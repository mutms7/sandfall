# Sandfall UI direction

The subject is a living pixel terrarium for curious people. The main job is to experiment with the world without hunting for tools.

Palette: forest #10201e, moss surface #1a2c27, fern border #3d5348, parchment text #edf1df, sage secondary #adbdaf, sand accent #ebcc91. Material colors supply the brighter accents.
Type: Bricolage Grotesque for short headings; DM Sans for controls and prose; JetBrains Mono for shortcuts and data.
Signature: a living landscape framed like a terrarium, with a full-width live world map beneath it. The original material-built logo stays.

Desktop: compact identity/header, world and playback on the left, tool library on the right, navigable map under the world. Mobile: world, playback, map, and compact tool library in a single column. The canvas uses a narrower camera on phones so cells stay legible.

Critique: automated skill results suggested a generic landing page, then neon esports. Neither fits this quiet sandbox. Use the skill's general accessibility and interaction guidance, with this purpose-built visual direction. Avoid decorative metrics, extra dashboards, excessive motion, or a marketing hero. The landscape is the memorable element.

Tutorial: four short practice steps (sand, water, people, Life), with observable completion and an optional skip. It uses an isolated practice world and restores the prior world and editing state on exit. The regular UI stays available.
